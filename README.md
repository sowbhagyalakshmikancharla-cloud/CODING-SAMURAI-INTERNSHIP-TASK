# Business Analytics Portfolio

Welcome to my portfolio! This repository contains 5 hands-on Business analytics projects focused on retail sales trends, employee demographics, workforce attrition, and basic predictive modeling. All projects were built using Excel/Google Sheets.

---

## 📊 Projects Overview

| Project | Dataset | Core Objective | Key Deliverables |
| :--- | :--- | :--- | :--- |
| **01. Sales Metrics** | Small Retail Sales | Calculate basic performance metrics | Revenue Summary & Top Products Chart |
| **02. Employee Demographics** | Small HR Dataset | Analyze workforce distribution | Department Split, Age & Gender Visuals |
| **03. Monthly Sales Trends** | Medium Regional Sales | Identify performance over time | Time-Series Line Chart & Regional Bar Chart |
| **04. Employee Attrition** | IBM HR Analytics | Find patterns in employee turnover | Attrition Rate & Exit Age Analysis |
| **05. Sales Predictions** | Extended Sales Data | Project future sales using trends | Next-Month Sales Projection Line Chart |

---

## 📂 Project Summary & Tasks

### 🏢 Project 1: Sales Metrics Dashboard
* **Objective:** Create a basic sales performance dashboard for a small retail store.
* **Tasks Completed:**
  1. Calculated total revenue, average order value, and total sales.
  2. Visualized monthly sales trends using line and bar charts.
  3. Identified and charted the top 3 selling products.

### 👥 Project 2: Employee Demographic Analysis
* **Objective:** Understand the demographic distribution of employees in a company.
* **Tasks Completed:**
  1. Analyzed how employees are distributed across different departments.
  2. Visualized the gender split using pie charts and age distribution using histograms.
  3. Found the average employee salary for each department.

### 📈 Project 3: Monthly Sales Trends and Analysis
* **Objective:** Identify regional sales trends over time.
* **Tasks Completed:**
  1. Calculated monthly sales totals and displayed them in a clean trend line chart.
  2. Identified the best-performing and worst-performing sales months.
  3. Analyzed and compared sales performance by geographic region using a bar chart.

### 📉 Project 4: Employee Attrition Insights
* **Objective:** Analyze basic attrition patterns to see why employees leave.
* **Tasks Completed:**
  1. Calculated the company's total employee attrition rate.
  2. Visualized attrition counts across departments using a bar chart.
  3. Identified the average age of employees leaving the company.

### 🔮 Project 5: Sales Predictions Using Basic Models
* **Objective:** Predict future sales metrics based on historical trends.
* **Tasks Completed:**
  1. Performed basic trendline analysis to project next month's sales totals.
  2. Visualized the historical sales trend alongside the future projection using a line chart.
  3. Suggested strategic business adjustments based on the observed trend direction.
